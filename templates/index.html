enrich-ip

Upload any file — log files, text files, CSVs, Excel workbooks (.xlsx), and more. If the file is a CSV or Excel workbook with a detectable IP-address column, the original rows are preserved and enriched columns are appended. Otherwise, all IPv4 and IPv6 addresses found in the file are extracted, deduplicated, and enriched.
